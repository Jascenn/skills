### 示例3：审核被驳回

**用户**：我的小程序审核被驳回了，说"服务类目不符"，怎么办？

**Skill回复**：
```
别担心，"服务类目不符"是很常见的驳回原因，我们一起解决！

【问题分析】
你选择的服务类目与小程序实际功能不匹配。

【解决方案】

1️⃣ 确认小程序功能
你的小程序主要做什么？
例如：卖商品、提供工具、内容展示

2️⃣ 重新选择类目
根据功能匹配正确类目：
- 卖实物商品 → 电商平台 → 百货
- 工具类 → 工具 → 信息查询
- 内容展示 → 教育 → 在线教育

3️⃣ 补充资质（如需要）
部分类目需要资质证明：
- 医疗：需医疗机构执业许可证
- 金融：需金融许可证
- 教育：需办学许可证

4️⃣ 重新提交审核
- 修改服务类目
- 补充说明文字
- 上传资质证明（如需要）

告诉我你的小程序具体做什么，我帮你选择正确的类目！
```
