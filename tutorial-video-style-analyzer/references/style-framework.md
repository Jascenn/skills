# Tutorial Video Style Framework

Use this reference when a user wants a general style system from a video, not just a one-off critique.

## Universal Style Extraction Grid

| Dimension | What To Look For | Reusable Output |
| --- | --- | --- |
| Positioning | Is it a tutorial, proof demo, course, review, sales walkthrough, or explainer? | The category of future videos this style fits |
| Hook | What appears in the first 3-5 seconds? | Opening formula |
| Proof Path | How does the video prove its claim? | Repeatable story structure |
| Screen Behavior | Zooms, cursor, cuts, split screen, UI scale | Editing rules |
| Copy Rhythm | Sentence length, filler, tone, repeated phrases | Voiceover rules |
| Subtitle Behavior | Transcription vs summary, line length, keyword emphasis | Caption rules |
| Visual Identity | Colors, logo, opener, background, overlays | Brand/visual rules |
| Trust Devices | Live operation, comparison, before/after, real output, errors | Evidence checklist |
| Ending | Summary, CTA, proof conclusion, next step | Closing formula |

## Common Tutorial Style Families

### Practical Proof Demo

Best for software, AI tools, API products, setup flows, and workflow upgrades.

Pattern:

```text
claim -> live operation -> visible proof -> comparison -> practical conclusion
```

Typical traits:

- real screen recording
- first-person narration
- side-by-side comparison
- large readable subtitles
- trust through observable actions

### Course-Lecture Clip

Best for conceptual teaching and paid course snippets.

Pattern:

```text
concept -> example -> explanation -> recap -> next step
```

Typical traits:

- more deliberate pacing
- more structured headings
- less cursor movement
- captions summarize key ideas rather than transcribe everything

### Product Walkthrough

Best for feature announcements and onboarding.

Pattern:

```text
problem -> feature -> workflow -> result -> call to action
```

Typical traits:

- polished opener
- clearer CTA
- more UI callouts
- shorter proof sequences

### Review/Comparison

Best for tool selection, alternatives, benchmarks, and buying decisions.

Pattern:

```text
criteria -> option A -> option B -> test -> verdict
```

Typical traits:

- visible criteria
- charts or side-by-side UI
- stronger verdict language
- more explicit tradeoffs

## Subtitle Density Rules

Use this as a default unless the source style clearly differs:

- 1 idea per subtitle beat
- 8-18 Chinese characters for mobile-first captions
- 2 lines maximum for dense explanations
- highlight nouns and outcome words, not whole sentences
- split parenthetical explanations into their own beat

Example:

```text
输入授权码
它类似验证码，但不会变
```

## Style Application Rule

When applying a reference style to a new topic:

1. Keep the timeline logic.
2. Keep the tone and caption behavior.
3. Replace all product-specific nouns.
4. Rebuild the proof path around the new topic's real evidence.
5. Do not copy claims that are only true for the reference video.
